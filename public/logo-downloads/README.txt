SCAURUS SVG LOGO PACK

16 standalone SVGs: SCAURUS, Quant, Digital and Pro marks and horizontal
wordmarks, each in black (for light backgrounds) and white (for dark backgrounds).
All backgrounds are transparent. All lettering is outlined from Outfit ExtraBold
(weight 800). No font installation, raster images or external resources required.
SVGs are resolution-independent: scale to any size without pixelation.

Provenance:
- SCAURUS main mark is a geometric vector reconstruction of the PNG used on the
  website, not an original designer-supplied vector master. Minor differences
  from the raster are possible; approve it before large-scale print production.
- Quant/Digital/Pro marks use the website's existing SVG geometry and Outfit.
- Product horizontal wordmarks are additional export lockups using those marks.
- This pack covers current SCAURUS branding, not retired Aittorney assets.

Open index.html for a self-contained visual sheet with individual download links.
The website's existing logos have not been replaced.
